# Photo Denoise 1.3.1

## Windows x64 installer

Download `PhotoDenoise-1.3.1-x64.msi`. The installer includes ONNX Runtime,
DirectML, LibRaw, the required Visual C++ runtime DLLs, licenses and the model
catalog. No Python or .NET runtime is required to run Photo Denoise.

Installation is per user in `%LOCALAPPDATA%\Programs\PhotoDenoise`. Start menu
shortcuts and a user PATH entry are provided; open a new terminal after installation.
Model weights download on demand into `models` beside `denoise.exe`.
Upgrades and uninstall preserve downloaded models and user files.

## Processing completion

After denoising, the TUI closes automatically, restores the terminal and exits
without waiting for Enter. Successful stdout contains only the absolute output
path and a newline, for both TUI and scripted runs. There is no `Saved:` prefix
or final timing summary. Script progress goes to stderr; failures return a
nonzero exit code and report the error on stderr.

```powershell
denoise.exe model
denoise.exe "E:\photos\moon.CR2" 25 --model scunet_color_15
```

The online catalog includes 13 profiles across SCUNet, NAFNet, Restormer,
SwinIR and DRUNet. Use `denoise.exe model` to browse descriptions and download
models, or select a model with `--model` while processing.

Compatible DirectML GPUs are tried first, with CPU fallback. RAW input is
developed to uncompressed 16-bit TIFF; source images are kept unchanged.
